Online Application

How to Apply

{% if is_student_scheme %}
  1. Open the official UMIS portal using the button below.
  2. Sign in using the student login details provided by your institution.
  3. Open the scheme/application section and choose the relevant scheme.
  4. Check your personal, school and college details.
  5. Complete the application and upload the requested documents.
  6. Review and submit the application.
  7. Save the acknowledgement and follow up for verification.
{% elif is_farmer_scheme %}
  1. Open the official scheme portal.
  2. Choose the relevant registration or application option.
  3. Enter the requested farmer and supporting details.
  4. Submit the required supporting documents.
  5. Submit the application and save the reference number.
  6. Check the application status.
{% elif is_pension_scheme %}
  1. Open the official pension portal.
  2. Find the relevant pension scheme.
  3. Follow the application process shown on the portal.
  4. Provide the requested supporting details.
  5. Submit and save the acknowledgement.
{% elif is_bank_scheme %}
  1. Open the official scheme website.
  2. Check the available enrolment method.
  3. Prepare the required documents.
  4. Complete the application or enrolment.
  5. Save the acknowledgement and follow up.
{% elif is_business_scheme %}
  1. Open the official scheme portal.
  2. Read the eligibility and application instructions.
  3. Register or sign in if required.
  4. Complete the application.
  5. Upload documents and submit.
  6. Save the reference number and follow up.
{% elif is_rural_employment %}
  1. Check the official MGNREGA process.
  2. Contact the Gram Panchayat about registration.
  3. Submit the required details.
  4. Request work and keep the acknowledgement.
  5. Check the application or work status.
{% elif is_rural_housing or is_urban_housing %}
  1. Open the official housing scheme portal.
  2. Check eligibility and the application process.
  3. Prepare the required supporting records.
  4. Follow the application and verification process.
  5. Save the reference and check status.
{% else %}
  1. Open the official scheme website.
  2. Find the scheme and read its instructions.
  3. Complete the application.
  4. Submit the requested documents.
  5. Submit and save the acknowledgement.
  6. Check the application status.
{% endif %}
Important: Follow the current instructions shown on the official scheme portal.
